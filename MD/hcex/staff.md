# การออกใบรับรองสุขอนามัย (Health Certificate) สินค้าแปรรูปด้านพืช

## สินค้าแปรรูปด้านพืช (ฝั่งเจ้าหน้าที่)

ระบบนี้ใช้สำหรับ **เจ้าหน้าที่กรมวิชาการเกษตร** ในการตรวจสอบคำขอ พิจารณาผล Lab ตรวจสอบแบบร่าง และดำเนินการออกใบรับรองสุขอนามัยพืชสำหรับ **สินค้าแปรรูปด้านพืช**

---

# 1. โครงสร้างระบบฝั่งเจ้าหน้าที่

ระบบแบ่งการทำงานหลักออกเป็น 4 ขั้นตอน
HC Processed Plant Product Officer System
│
├─ Step 1 : ข้อมูลคำขอ
├─ Step 2 : พิจารณาออกใบรับรอง
├─ Step 3 : พิจารณาแบบร่าง
└─ Step 4 : ลงนาม

---

# 2. Sidebar Menu (เมนูระบบ)

เมนูด้านซ้ายใช้สำหรับจัดการกระบวนการออกใบรับรอง

## คำขอออกใบรับรอง

### รายการคำขอทั้งหมด

แสดงรายการคำขอทั้งหมดในระบบ

สามารถ

- ดูรายละเอียดคำขอ
- ค้นหาคำขอ
- กรองตามสถานะ

---

### ตรวจสอบคำขอ

เจ้าหน้าที่ตรวจสอบข้อมูล เช่น

- ข้อมูลผู้ส่งออก
- รายละเอียดสินค้า
- ผล Lab

---

### พิจารณาออกใบรับรอง

ขั้นตอนการตัดสินใจว่า

- ออกใบรับรอง
- ส่งให้พิจารณาแบบร่าง
- ไม่ผ่าน

---

### พิจารณาแบบร่าง

ตรวจสอบ **Draft ใบรับรอง**

เช่น

- ข้อมูลสินค้า
- ประเทศปลายทาง
- รายละเอียดสินค้า

---

## คำขอพิจารณาผล Lab

ใช้สำหรับ

- ตรวจสอบผล Lab
- อนุมัติผล Lab ก่อนนำไปใช้ในคำขอ

---

## ลงนาม

ผู้มีอำนาจลงนามสามารถ

- ลงนามใบรับรอง
- อนุมัติเอกสาร

---

## ข้อมูลทะเบียน

จัดการข้อมูลทะเบียน เช่น

- ผู้ส่งออก
- โรงงาน
- สถานที่ผลิต

---

## ข้อมูลภาพรวม

Dashboard แสดง

- จำนวนคำขอ
- สถานะคำขอ
- จำนวนใบรับรอง

---

# 3. หน้ารายการคำขอ

เจ้าหน้าที่สามารถค้นหาคำขอโดย

- วันที่ยื่น
- ประเภทคำขอ
- สถานะคำขอ

ตารางข้อมูล

| Field        | รายละเอียด     |
| ------------ | -------------- |
| เลขคำขอ      | หมายเลขคำขอ    |
| ประเภทคำขอ   | ประเภทเอกสาร   |
| ผู้ประกอบการ | ผู้ยื่นคำขอ    |
| วันที่ยื่น   | วันที่ยื่นคำขอ |
| สถานะ        | สถานะกระบวนการ |
| Action       | ปุ่มดำเนินการ  |

---

# 4. Workflow การดำเนินงานของเจ้าหน้าที่

1 ข้อมูลคำขอ
2 พิจารณาออกใบรับรอง
3 พิจารณาแบบร่าง
4 ลงนาม

---

# 5. Step 1 : ข้อมูลคำขอ

เจ้าหน้าที่ตรวจสอบ

- ข้อมูลผู้ส่งออก
- รายละเอียดสินค้า
- เอกสารแนบ
- ผล Lab

หากข้อมูลไม่ถูกต้อง

- ส่งกลับให้ผู้ประกอบการ **แก้ไขคำขอ**

---

# 6. Step 2 : พิจารณาออกใบรับรอง

เจ้าหน้าที่พิจารณาว่าคำขอสามารถออกใบรับรองได้หรือไม่

ตัวเลือกการตัดสินใจ

| ตัวเลือก          | ความหมาย             |
| ----------------- | -------------------- |
| จัดทำใบรับรอง     | ดำเนินการออกใบรับรอง |
| ส่งพิจารณาแบบร่าง | ส่งไปตรวจสอบ Draft   |
| ไม่ผ่าน           | ปฏิเสธคำขอ           |

สามารถระบุ

- หมายเหตุ
- เหตุผลการพิจารณา

---

# 7. Step 3 : พิจารณาแบบร่าง

เจ้าหน้าที่ตรวจสอบ

- Draft Certificate
- ความถูกต้องของข้อมูล

ตัวเลือก

| ตัวเลือก          | ความหมาย           |
| ----------------- | ------------------ |
| จัดทำใบรับรอง     | ผ่านการตรวจแบบร่าง |
| ส่งพิจารณาแบบร่าง | ส่งตรวจเพิ่มเติม   |
| ไม่ผ่าน           | ปฏิเสธคำขอ         |

หากผ่าน

- เลือกผู้ลงนาม

---

# 8. Step 4 : ลงนาม

ผู้มีอำนาจลงนามจะ

- ลงนามใบรับรอง
- อนุมัติเอกสาร

เมื่อเสร็จแล้วระบบจะ

- Generate ใบรับรอง
- เปลี่ยนสถานะคำขอเป็น **Completed**

---

# 9. สถานะคำขอในระบบ

| Status           | ความหมาย           |
| ---------------- | ------------------ |
| Draft            | แบบร่าง            |
| Submitted        | ยื่นคำขอแล้ว       |
| Under Review     | อยู่ระหว่างตรวจสอบ |
| Pending Approval | รอพิจารณา          |
| Draft Review     | ตรวจสอบแบบร่าง     |
| Approved         | อนุมัติ            |
| Rejected         | ไม่ผ่าน            |
| Completed        | ออกใบรับรองแล้ว    |

---
