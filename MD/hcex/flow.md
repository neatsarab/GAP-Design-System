# กระบวนการยื่นคำขอใบรับรองสุขอนามัย (Health Certificate)

## สินค้าแปรรูปด้านพืช

กระบวนการนี้แสดงขั้นตอนการยื่นคำขอและการพิจารณาออกใบรับรองสุขอนามัยสำหรับสินค้าแปรรูปด้านพืช โดยมีผู้เกี่ยวข้อง 3 บทบาท ได้แก่

- ผู้ประกอบการ
- เจ้าหน้าที่
- ผู้มีอำนาจลงนาม

---

# 1. ผู้ประกอบการยื่นคำขอ

ผู้ประกอบการเริ่มต้นกระบวนการโดย

1. เลือกคำขอที่ต้องการยื่น
2. ระบบจะแยกเป็น 2 กรณี

### กรณีที่ 1 : มีผล Lab ผ่านการพิจารณาแล้ว

- ผู้ประกอบการสามารถเลือกผล Lab ที่ผ่านการพิจารณาแล้วมาใช้ในคำขอ
- จากนั้นดำเนินการยื่นคำขอในระบบ

### กรณีที่ 2 : ยังไม่มีผล Lab

- ผู้ประกอบการยื่นคำขอผล Lab
- ระบบจะส่งคำขอไปยังห้องปฏิบัติการเพื่อตรวจตัวอย่าง
- เมื่อผล Lab ออกแล้วสามารถนำมาใช้ในคำขอ

---

# 2. เจ้าหน้าที่ตรวจสอบคำขอ

เจ้าหน้าที่ดำเนินการ

- ตรวจสอบความถูกต้องของข้อมูล
- ตรวจสอบเอกสารประกอบ
- ตรวจสอบผล Lab

### การตัดสินใจ

| ผลการตรวจ | การดำเนินการ                      |
| --------- | --------------------------------- |
| ไม่ผ่าน   | ส่งกลับให้ผู้ประกอบการแก้ไขข้อมูล |
| ผ่าน      | ดำเนินการออกใบรับรอง              |

---

# 3. การออกใบรับรอง (Preview Certificate)

เมื่อคำขอผ่านการตรวจสอบ

เจ้าหน้าที่จะ

- สร้างแบบร่างใบรับรอง (Preview Certificate)
- ส่งให้ผู้ประกอบการตรวจสอบข้อมูล

ผู้ประกอบการสามารถ

- ยืนยันข้อมูล
- ขอแก้ไขข้อมูล

---

# 4. การส่งให้ผู้มีอำนาจลงนาม

เมื่อข้อมูลถูกต้อง

ระบบจะ

1. ออกใบรับรองสุขอนามัย
2. สร้างเลขใบรับรอง
3. ส่งคำขอให้ผู้มีอำนาจลงนาม

สามารถส่งให้

- ผู้มีอำนาจลงนามคนที่ 1
- ผู้มีอำนาจลงนามคนที่ 2
- ผู้มีอำนาจลงนามคนที่ 3

---

# 5. การพิจารณาของผู้มีอำนาจลงนาม

ผู้มีอำนาจลงนามจะพิจารณา

### กรณีต้องแก้ไข

- ส่งกลับให้เจ้าหน้าที่แก้ไขข้อมูล

### กรณีอนุมัติ

- ลงนามในใบรับรอง

---

# 6. การรับใบรับรอง

หลังจากลงนามเรียบร้อย

ผู้ประกอบการดำเนินการ

1. ชำระค่าธรรมเนียม
2. รับใบรับรองสุขอนามัย

---

# 7. สรุป Flow การทำงาน

Start
│
├─ ผู้ประกอบการเลือกคำขอ
│
├─ มีผล Lab แล้ว ?
│ │
│ ├─ มีผล Lab → ยื่นคำขอ
│ │
│ └─ ไม่มีผล Lab
│ └─ ขอผล Lab
│
├─ เจ้าหน้าที่ตรวจสอบคำขอ
│ │
│ ├─ ไม่ผ่าน → แก้ไขข้อมูล
│ │
│ └─ ผ่าน
│ │
│ └─ สร้าง Preview Certificate
│
├─ ผู้ประกอบการยืนยันข้อมูล
│
├─ ส่งให้ผู้มีอำนาจลงนาม
│
├─ ลงนาม
│
├─ ผู้ประกอบการชำระค่าธรรมเนียม
│
└─ รับใบรับรอง
End
