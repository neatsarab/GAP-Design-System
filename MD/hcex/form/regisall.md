# การออกใบรับรองสุขอนามัย (Health Certificate) สินค้าแปรรูปด้านพืช

## กรณียื่นขอทำทะเบียนประวัติ : แต่ละรุ่นการผลิต

> ใช้สำหรับกรณีผู้ประกอบการเลือก "แต่ละรุ่นการผลิต" โดยไม่บังคับว่าต้องมีข้อมูลจาก DOA และสามารถกรอกมาตรฐานการผลิตเองได้

---

# ขั้นตอนการดำเนินการ

1. ข้อมูลรายละเอียด
2. แนบไฟล์

> หน้าปัจจุบัน: ขั้นตอนที่ 1 ข้อมูลรายละเอียด

---

# ประเภทการยื่น

- [ ] ทั้งระบบการผลิต
- [x] แต่ละรุ่นการผลิต

> กรณีนี้ไม่บังคับให้มีทะเบียนโรงงานจาก DOA

# 4. มาตรฐานการผลิตของโรงงาน

## 4.1 มาตรฐานหลัก

ผู้ใช้สามารถกรอกมาตรฐานที่โรงงานได้รับเอง

| ชื่อมาตรฐาน | หน่วยงานที่รับรอง | หมายเลขการรับรอง | วันที่หมดอายุ |
| ----------- | ----------------- | ---------------- | ------------- |
| text input  | text input        | text input       | date picker   |

ตัวอย่างมาตรฐาน

- GMP
- HACCP
- ISO 22000
- BRC
- HALAL
- Organic

ปุ่มการทำงาน

- `เพิ่มมาตรฐาน`
- `ลบ`

> ต้องมีอย่างน้อย 1 รายการ

---

## 4.2 มาตรฐานเพิ่มเติม

สามารถเพิ่มมาตรฐานอื่นเพิ่มเติมได้ไม่จำกัด

| ชื่อมาตรฐาน | หน่วยงานที่รับรอง | หมายเลขการรับรอง | วันที่หมดอายุ |

| text input  | text input        | text input       | date picker   |
