# การออกใบรับรองสุขอนามัย (Health Certificate) สินค้าแปรรูปด้านพืช

## คำขอพิจารณาผล Lab

> ใช้สำหรับยื่นคำขอพิจารณาผลตรวจทางห้องปฏิบัติการ (Lab Result) ของสินค้าแปรรูปด้านพืช เพื่อใช้ประกอบการออกใบรับรองสุขอนามัย

---

# ขั้นตอนการดำเนินการ

1. ข้อมูลรายละเอียด
2. ไฟล์แนบ

---

# ขั้นตอนที่ 1 : ข้อมูลรายละเอียด

## แนวทางการกรอกข้อมูล

1. เลือกผู้ผลิตจากทะเบียนประวัติที่เคยบันทึกไว้
2. เลือกผลิตภัณฑ์จากรายการที่อยู่ในทะเบียนประวัติของผู้ผลิต
3. ระบบดึงข้อมูลจากทะเบียนประวัติมาแสดงอัตโนมัติ และผู้ใช้สามารถกรอกข้อมูลเพิ่มเติมได้
4. สามารถเลือกประเทศปลายทางได้มากกว่า 1 ประเทศ

---

# 14. รายการทดสอบตามมาตรฐานที่ใช้ส่งออก

- ประเทศปลายทาง
- มาตรฐานสินค้า
- ข้อมูลทะเบียนประวัติ

ตัวอย่างรายการทดสอบ

- Sulfites
- Total Plate Count
- Total Mold Count
- Escherichia coli
- Staphylococcus aureus
- Salmonella spp.
- Clostridium perfringens
- Bacillus cereus

> ผู้ใช้ไม่สามารถแก้ไขรายการทดสอบได้ หากมาจากมาตรฐานที่กำหนดไว้

หมายเหตุ

- ระบบต้องแสดงเอกสารอ้างอิงของมาตรฐานที่ใช้ในการกำหนดรายการทดสอบ

# ขั้นตอนที่ 2 : ไฟล์แนบ

> ต้องแนบไฟล์ผลทดสอบ (Test Report) อย่างน้อย 1 ไฟล์

## เอกสารที่รองรับ

- ผล Test Report
- กรมวิชาการเกษตร 29 (กมพ.29)
- เอกสารอ้างอิงอื่น ๆ

| ประเภทเอกสาร | จำนวนขั้นต่ำ  |
| ------------ | ------------- |
| Test Report  | มากกว่า 0     |
| กมพ.29       | 0 หรือมากกว่า |

รองรับไฟล์ประเภท

- PDF
- JPG
- JPEG
- PNG

ขนาดไฟล์ไม่เกิน 10 MB ต่อไฟล์

# Validation / เงื่อนไขระบบ

## ข้อมูลทั่วไป

- ต้องเลือกผู้ผลิตจากทะเบียนประวัติ
- ต้องเลือกผลิตภัณฑ์จากทะเบียนประวัติของผู้ผลิตที่เลือก
- ต้องกรอกวันที่สุ่มเก็บตัวอย่าง วันที่ผลิต และวันหมดอายุ
- วันหมดอายุต้องมากกว่าวันที่ผลิต
- วันที่นำส่งตัวอย่างต้องไม่น้อยกว่าวันที่สุ่มเก็บตัวอย่าง

## ประเทศปลายทาง

- ต้องเลือกประเทศปลายทางอย่างน้อย 1 ประเทศ
- หากเลือก USA / CANADA ต้องแสดงรายการทดสอบเฉพาะของประเทศนั้น

## ปริมาณการส่งออก

- ต้องกรอกจำนวนมากกว่า 0
- ต้องเลือกหน่วยอย่างน้อย 1 หน่วย

## Special Remark

- หากเลือกข้อความพิเศษ ต้องกรอกข้อความอย่างน้อย 1 รายการ

## ไฟล์แนบ

- ต้องแนบ Test Report อย่างน้อย 1 ไฟล์
- รองรับการแนบหลายไฟล์
