# รายละเอียดสินค้า

> 1 ผู้ผลิต ต่อ 1 ใบคำขอ

| ลำดับ | รายการสินค้าเพื่อส่งออกด้านพืช | ประเทศปลายทาง            | มาตรฐานสินค้า | รายการทดสอบ    |
| ----- | ------------------------------ | ------------------------ | ------------- | -------------- |
| 1     | text input                     | เลือกได้มากกว่า 1 ประเทศ | text input    | เลือกจากรายการ |

เงื่อนไข

- 1 รายการสินค้า สามารถเลือกประเทศปลายทางได้มากกว่า 1 ประเทศ
- หากมีหลายประเทศ ระบบต้องสามารถเพิ่มประเทศในแถวเดียวกันได้
- 1 ใบคำขอ สามารถมีสินค้าได้มากกว่า 1 รายการ

ปุ่มการทำงาน

- `เพิ่มสินค้า`
- `ลบสินค้า`

---

## รายการทดสอบ

สามารถเลือกได้มากกว่า 1 รายการต่อสินค้า

| รายการทดสอบ             | เกณฑ์มาตรฐาน      |
| ----------------------- | ----------------- |
| Sulfites                | ≤ 30 mg/kg        |
| Total Plate Count       | ≤ 1.0 × 10⁶ CFU/g |
| Total Mold Count        | ≤ 1.0 × 10² CFU/g |
| Escherichia coli        | ≤ 3.0 MPN/g       |
| Staphylococcus aureus   | ND in 0.1 g       |
| Salmonella spp.         | ND in 25 g        |
| Clostridium perfringens | ≤ 1.0 × 10³ CFU/g |
| Bacillus cereus         | ≤ 1.0 × 10³ CFU/g |

> ผู้ใช้สามารถเลือกหลายรายการต่อสินค้าได้

# Validation / เงื่อนไขระบบ

## ข้อมูลผู้ผลิต

- ต้องกรอกชื่อบริษัทผู้ผลิต
- ต้องกรอกข้อมูลผู้ประสานงานอย่างน้อยชื่อและเบอร์โทรศัพท์

## มาตรฐานการผลิต

- ต้องมีมาตรฐานอย่างน้อย 1 รายการ
- ทุกแถวของมาตรฐานต้องกรอก
  - ชื่อมาตรฐาน
  - หน่วยงานที่รับรอง
  - หมายเลขการรับรอง
  - วันที่หมดอายุ

## รายละเอียดสินค้า

- ต้องมีสินค้าอย่างน้อย 1 รายการ
- ต้องเลือกประเทศปลายทางอย่างน้อย 1 ประเทศต่อสินค้า
- ต้องมีรายการทดสอบอย่างน้อย 1 รายการต่อสินค้า

## เอกสารแนบ

- ต้องแนบเอกสารอย่างน้อย 1 ไฟล์
- หากมีการกรอกมาตรฐานในข้อ 4 ระบบควรแนะนำให้แนบใบรับรองของมาตรฐานนั้น
