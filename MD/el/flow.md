# กระบวนการของระบบการควบคุมพิเศษระบบบัญชีรายชื่อโรงคัดบรรจุ (Establishment List)

กระบวนการนี้ใช้สำหรับการขึ้นทะเบียนสถานประกอบการ (โรงคัดบรรจุ) เพื่อให้สามารถอยู่ในบัญชีรายชื่อ Establishment List ของกรมวิชาการเกษตร โดยมีหน่วยงานที่เกี่ยวข้องดังนี้

- ผู้ประกอบการ
- ด่านเกษตร
- สวพ. (สำนักวิจัยและพัฒนาการเกษตร)
- คณะกรรมการ EL

---

# 1. ผู้ประกอบการยื่นคำขอ

ผู้ประกอบการดำเนินการผ่านระบบดังนี้

1. เข้าใช้งานระบบ
2. เลือกเมนู **การขอขึ้นทะเบียน EL**
3. สร้างคำขอใหม่
4. กรอกข้อมูลสถานประกอบการ
5. แนบเอกสารที่เกี่ยวข้อง
6. บันทึกและส่งคำขอ

---

# 2. ด่านเกษตรตรวจสอบคำขอ

ด่านเกษตรทำหน้าที่ตรวจสอบความถูกต้องของข้อมูลและเอกสาร

### ผลการตรวจสอบ

| ผลการตรวจ                 | การดำเนินการ                |
| ------------------------- | --------------------------- |
| ข้อมูลไม่ครบ / ไม่ถูกต้อง | ส่งกลับให้ผู้ประกอบการแก้ไข |
| ถูกต้อง                   | ส่งต่อไปยัง สวพ.            |

---

# 3. สวพ. ตรวจสอบคำขอ

สวพ. ดำเนินการ

- ตรวจสอบความถูกต้องของเอกสาร
- ตรวจสอบคุณสมบัติสถานประกอบการ

### ผลการตรวจสอบ

| ผลการตรวจ | การดำเนินการ                      |
| --------- | --------------------------------- |
| ไม่ผ่าน   | ส่งกลับให้แก้ไข                   |
| ผ่าน      | ดำเนินการตรวจประเมินสถานประกอบการ |

---

# 4. การตรวจประเมินสถานประกอบการ

เจ้าหน้าที่ดำเนินการ

1. เตรียมการตรวจประเมิน
2. ลงพื้นที่ตรวจประเมินสถานประกอบการ
3. จัดทำรายงานผลการตรวจ

### ผลการตรวจประเมิน

| ผลการตรวจ | การดำเนินการ              |
| --------- | ------------------------- |
| ไม่ผ่าน   | แจ้งผู้ประกอบการแก้ไข     |
| ผ่าน      | เสนอคณะกรรมการ EL พิจารณา |

---

# 5. คณะกรรมการ EL พิจารณา

คณะกรรมการพิจารณารายงานผลการตรวจประเมิน

### ผลการพิจารณา

| ผลการพิจารณา | การดำเนินการ             |
| ------------ | ------------------------ |
| ไม่อนุมัติ   | แจ้งผู้ประกอบการแก้ไข    |
| อนุมัติ      | ขึ้นทะเบียนสถานประกอบการ |

---

# 6. การขึ้นทะเบียน Establishment List

เมื่อผ่านการพิจารณา

ระบบจะดำเนินการ

1. บันทึกสถานประกอบการเข้าสู่บัญชี EL
2. ออกเลขทะเบียนสถานประกอบการ
3. แจ้งผลการพิจารณาให้ผู้ประกอบการ

---

# 7. ผู้ประกอบการรับผล

ผู้ประกอบการสามารถ

- ตรวจสอบผลการพิจารณาในระบบ
- ดาวน์โหลดเอกสารการขึ้นทะเบียน
- ใช้เลขทะเบียนในการดำเนินการส่งออก
