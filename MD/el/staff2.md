# ระบบการควบคุมพิเศษบัญชีรายชื่อโรงคัดบรรจุ (Establishment List : EL)

## ฝั่งเจ้าหน้าที่ ศวพ. (ศูนย์วิจัยและพัฒนาการเกษตร)

ระบบนี้ใช้สำหรับเจ้าหน้าที่ **ศวพ.** ในการดำเนินการตรวจประเมินแปลงเกษตรกรและตรวจติดตามตามแบบฟอร์ม **CL-02** เพื่อควบคุมมาตรฐานการผลิตของเกษตรกรที่อยู่ในเครือข่ายของโรงคัดบรรจุ (Establishment List)

---

# 1. Information Architecture (IA)

เมนูหลักที่เจ้าหน้าที่ ศวพ. ใช้งาน

- รายการตรวจเอกสาร GAP
- รายการตรวจ GAP
- รอตรวจติดตาม
- เกษตรกร
- แปลงเกษตรกร
- แจ้งเตือน
- Report
- เปลี่ยน Password

---

# 2. หน้าที่ของเจ้าหน้าที่ ศวพ.

เจ้าหน้าที่ ศวพ. มีหน้าที่หลักในการ

- ตรวจประเมินแปลงเกษตรกร
- ตรวจติดตามมาตรฐานการผลิต
- บันทึกผลการตรวจในแบบฟอร์ม CL-02
- แนบหลักฐานและภาพถ่าย
- รายงานผลให้หน่วยงานระดับ สวพ.

---

# 3. ข้อมูลแปลงเกษตรกรที่ต้องตรวจสอบ

เจ้าหน้าที่ต้องตรวจสอบข้อมูลพื้นฐาน เช่น

- ชื่อเกษตรกร
- ชนิดพืช
- ประเภทการตรวจ (ตรวจขึ้นทะเบียนใหม่ / ตรวจติดตาม)
- เลขที่แปลง
- รหัสใบรับรอง GAP
- ขนาดพื้นที่ปลูก
- ที่ตั้งแปลง
- จังหวัด / อำเภอ / ตำบล
- พิกัดแปลง (X,Y,Z)
- โรงคัดบรรจุที่สังกัด

---

# 4. รายการตรวจประเมิน (CL-02)

เจ้าหน้าที่ต้องตรวจสอบรายการตามแบบฟอร์ม CL-02 เช่น

### 1. ระบบการตรวจติดตามแปลง

- มีการบันทึกการตรวจติดตามแปลงพืช

### 2. การประเมินความเสี่ยง

- ผู้ประกอบการมีการประเมินความเสี่ยงของพื้นที่เพาะปลูก

### 3. การตรวจสารตกค้าง

- มีการสุ่มตรวจสารเคมีตกค้างและจุลินทรีย์

### 4. ระบบทะเบียนเกษตรกร

- มีการควบคุมทะเบียนแปลง (AVL)

### 5. การฝึกอบรมเกษตรกร

- การใช้สารเคมี
- การป้องกันการปนเปื้อน
- การจัดการศัตรูพืช
- การจัดการหลังการเก็บเกี่ยว

### 6. การควบคุมอื่น ๆ

เช่น

- สถานที่คัดแยกผลผลิต
- การควบคุมสารเคมี
- การป้องกันการปนเปื้อน
- การบันทึกข้อมูลการผลิต

---

# 5. การบันทึกผลการตรวจ

เจ้าหน้าที่บันทึกผลการตรวจในแต่ละรายการ

ตัวเลือกผลการตรวจ

- ใช่ / มี
- ไม่ใช่ / ไม่มี

พร้อมระบุ

- เหตุผล
- เอกสารประกอบ
- หลักฐาน

---

# 6. สรุปผลการตรวจ

เมื่อการตรวจเสร็จสิ้น เจ้าหน้าที่จะสรุปผลการตรวจ

ผลการประเมิน

- ผ่าน
- ไม่ผ่าน

พร้อมระบุ

- หมายเหตุ
- ข้อเสนอแนะในการปรับปรุง

---

# 7. การแนบหลักฐาน

เจ้าหน้าที่ต้องแนบหลักฐานประกอบ เช่น

- ลายเซ็นเกษตรกร
- ภาพถ่ายแปลงเกษตร
- ภาพถ่ายพื้นที่ตรวจ

ตัวอย่างไฟล์

- ภาพถ่ายแปลงเกษตร 1
- ภาพถ่ายแปลงเกษตร 2
- ภาพถ่ายแปลงเกษตร 3
- ภาพถ่ายแปลงเกษตร 4

---

# 8. ข้อมูลการตรวจ

ระบบจะบันทึกข้อมูลการตรวจ เช่น

- ผู้ตรวจ
- สถานะ
- วันที่ตรวจ
- กำหนดการตรวจ
- วันที่สร้างข้อมูล
- วันที่แก้ไขข้อมูล

---

# 9. ผลลัพธ์ของกระบวนการ

หลังจากเจ้าหน้าที่บันทึกผลแล้ว

- ระบบจะส่งผลการตรวจไปยัง **สวพ.**
- ใช้ประกอบการพิจารณาสถานะของโรงคัดบรรจุในบัญชี EL
- ใช้เป็นข้อมูลสำหรับการตรวจติดตามครั้งถัดไป

---

# 10. สรุป Flow การทำงาน

รับรายการตรวจจากระบบ EL
│
เจ้าหน้าที่ ศวพ. ตรวจสอบข้อมูลแปลงเกษตรกร
│
ลงพื้นที่ตรวจแปลง
│
บันทึกผลการตรวจในแบบฟอร์ม CL-02
│
แนบภาพถ่ายและหลักฐาน
│
สรุปผล (ผ่าน / ไม่ผ่าน)
│
บันทึกข้อมูลในระบบ
│
ส่งรายงานไปยัง สวพ.
