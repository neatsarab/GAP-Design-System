# ระบบการควบคุมพิเศษบัญชีรายชื่อโรงคัดบรรจุ (Establishment List : EL)

## ฝั่งผู้ประกอบการ

ระบบนี้ใช้สำหรับ **ผู้ประกอบการโรงคัดบรรจุ** ในการยื่นคำขอขึ้นทะเบียนบัญชีรายชื่อโรงคัดบรรจุ (Establishment List : EL) พร้อมแนบข้อมูลเกษตรกร แปลงเกษตร และเอกสารมาตรฐานของโรงคัดบรรจุ เพื่อให้หน่วยงานของกรมวิชาการเกษตรตรวจประเมิน

---

# 1. Information Architecture (IA)

เมนูหลักของผู้ประกอบการ

- การยื่นคำขอ
- รายการคำขอ
- ข้อมูลทะเบียน

---

# 2. ขั้นตอนการยื่นคำขอ

กระบวนการยื่นคำขอประกอบด้วย 2 ขั้นตอนหลัก

1. ข้อมูลรายละเอียด
2. ไฟล์แนบ

ผู้ประกอบการสามารถ

- บันทึกแบบร่าง
- ยืนยันคำขอ

---

# 3. ข้อมูลเกษตรกร

ผู้ประกอบการต้องเพิ่มข้อมูลเกษตรกรที่อยู่ในเครือข่าย

ข้อมูลที่ต้องกรอก เช่น

- ประเภทเกษตรกร
  - บุคคลธรรมดา
  - นิติบุคคล
  - กลุ่มเกษตรกร
- เลขบัตรประชาชน / เลขนิติบุคคล
- ชื่อเกษตรกร
- ที่อยู่
- จังหวัด / อำเภอ / ตำบล
- รหัสไปรษณีย์
- เบอร์โทรศัพท์
- อีเมล

---

# 4. ข้อมูลแปลงเกษตร

ผู้ประกอบการต้องระบุข้อมูลแปลงเกษตรของเกษตรกร

ข้อมูลสำคัญ เช่น

- ชื่อเกษตรกร
- ชนิดพืช
- ประเภทการรับรอง (เช่น GAP)
- รหัสใบรับรอง
- พื้นที่เพาะปลูก
- ผลผลิตเฉลี่ย
- ที่ตั้งแปลง
- จังหวัด / อำเภอ / ตำบล
- พิกัดแปลง (X,Y,Z)

---

# 5. เอกสารประกอบการขึ้นทะเบียน

ผู้ประกอบการต้องแนบเอกสารประกอบ เช่น

### 1. เอกสารแปลงเกษตร

- แผนที่แปลง
- สำเนาใบรับรอง GAP
- สัญญาระหว่างเกษตรกรและโรงคัดบรรจุ (Farm Contract)

---

### 2. แผนการควบคุมแปลงเกษตร

- แผนการตรวจติดตามแปลง
- การจัดการสารเคมี
- การจัดการปุ๋ย
- การจัดการศัตรูพืช
- การเก็บเกี่ยวและการจัดการหลังการเก็บเกี่ยว

---

### 3. เอกสารด้านความปลอดภัยอาหาร

- การควบคุมสารตกค้าง
- การควบคุมการปนเปื้อน
- การตรวจสอบย้อนกลับ

---

# 6. ระบบการจัดการโรงคัดบรรจุ

ผู้ประกอบการต้องกรอกข้อมูลระบบการจัดการโรงคัดบรรจุ เช่น

- ชนิดพืชที่ดำเนินการ
- ระบบการจัดการคุณภาพ
- ระบบการควบคุมกระบวนการผลิต

---

# 7. เอกสารมาตรฐานโรงคัดบรรจุ

### 1. ใบรับรอง GMP

ข้อมูลที่ต้องระบุ

- หมายเลขใบรับรอง
- วันที่ออกใบรับรอง
- วันหมดอายุ

---

### 2. ใบรับรอง HACCP

ข้อมูลที่ต้องระบุ

- หมายเลขใบรับรอง
- วันที่ออกใบรับรอง
- วันหมดอายุ

---

# 8. เอกสารระบบ HACCP

เอกสารที่ต้องแนบ เช่น

- HACCP Team
- รายละเอียดผลิตภัณฑ์
- Flow Chart กระบวนการผลิต
- HACCP Plan
- CCP Validation
- HACCP Verification

---

# 9. เอกสารอื่น ๆ

เอกสารเพิ่มเติม เช่น

- Vendor List (AVL)
- ระบบตรวจสอบย้อนกลับ
- ระบบเรียกคืนสินค้า (Mock Recall)

---

# 10. การบันทึกและยืนยันคำขอ

ผู้ประกอบการสามารถ

- บันทึกข้อมูล
- แก้ไขข้อมูล
- ยืนยันคำขอเพื่อส่งให้หน่วยงานตรวจสอบ

เมื่อยืนยันคำขอแล้ว ระบบจะส่งข้อมูลไปยัง

- ศวพ.
- สวพ.
- คณะกรรมการ EL

เพื่อดำเนินการตรวจประเมิน

---

# 11. สรุป Flow การทำงาน

ผู้ประกอบการสร้างคำขอขึ้นทะเบียน EL
│
เพิ่มข้อมูลเกษตรกร
│
เพิ่มข้อมูลแปลงเกษตร
│
แนบเอกสารประกอบ
│
กรอกข้อมูลระบบโรงคัดบรรจุ
│
แนบเอกสาร GMP / HACCP
│
บันทึกข้อมูล
│
ยืนยันคำขอ
│
ส่งให้หน่วยงานตรวจสอบ

---

# 12. ผลลัพธ์ของกระบวนการ

เมื่อส่งคำขอแล้ว

- หน่วยงานภาครัฐจะตรวจสอบข้อมูล
- ดำเนินการตรวจประเมิน
- พิจารณาการขึ้นทะเบียนในบัญชี **Establishment List (EL)**
