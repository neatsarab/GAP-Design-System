# ผลตรวจ GMP / HACCP

แท็บนี้ใช้สำหรับบันทึกและแสดง **ผลการตรวจมาตรฐาน GMP และ HACCP** ของสถานประกอบการ

---

## แท็บในหน้าจอ

- GMP / HACCP
- ผลตรวจวิเคราะห์
- ผลสอบ

---

# 1. GMP

ปุ่มการทำงาน

- ➕ **สร้างใหม่** : เพิ่มข้อมูลการตรวจ GMP

## ตารางผลการตรวจ GMP

| ดู / แก้ไข | ครั้งที่ตรวจ | กำหนดตรวจ | วันที่ตรวจ | ผู้ตรวจ            | ผลการตรวจ | หมายเหตุ                                                     |
| ---------- | ------------ | --------- | ---------- | ------------------ | --------- | ------------------------------------------------------------ |
| ✏️         | 1            | -         | 29/11/2011 | น.ส.วรัญญา ปานเกตุ | ผ่าน      | โรงคัดบรรจุได้รับการขึ้นทะเบียนพืชพักแล้ว ตั้งแต่ 29/11/2011 |

### รายละเอียด Field

| Field        | Description                  |
| ------------ | ---------------------------- |
| ดู / แก้ไข   | เปิดดูหรือแก้ไขข้อมูลการตรวจ |
| ครั้งที่ตรวจ | ลำดับการตรวจ                 |
| กำหนดตรวจ    | วันที่กำหนดการตรวจ           |
| วันที่ตรวจ   | วันที่ดำเนินการตรวจจริง      |
| ผู้ตรวจ      | ชื่อเจ้าหน้าที่ผู้ตรวจ       |
| ผลการตรวจ    | ผ่าน / ไม่ผ่าน               |
| หมายเหตุ     | ข้อสังเกตเพิ่มเติม           |
