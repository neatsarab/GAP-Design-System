# ระบบการควบคุมพิเศษบัญชีรายชื่อโรงคัดบรรจุ (Establishment List : EL)

## ฝั่งเจ้าหน้าที่ กตม. (คณะกรรมการกลั่นกรองการตรวจประเมิน)

ระบบนี้ใช้สำหรับ **คณะกรรมการกลั่นกรองการตรวจประเมิน (กตม.)** ในการตรวจสอบเอกสารและพิจารณาคุณสมบัติของโรงคัดบรรจุ ก่อนอนุมัติให้อยู่ในบัญชี **Establishment List (EL)** ของกรมวิชาการเกษตร

---

# 1. Information Architecture (IA)

เมนูหลักที่เจ้าหน้าที่ กตม. ใช้งาน

- งานตรวจโรงคัดบรรจุ
- ตรวจเอกสารโรงคัดบรรจุ
- รอการตรวจติดตาม
- โรงคัดบรรจุ
- แจ้งเตือน
- Report
- เปลี่ยน Password

---

# 2. หน้าที่ของเจ้าหน้าที่ กตม.

เจ้าหน้าที่ กตม. ทำหน้าที่

- ตรวจสอบข้อมูลโรงคัดบรรจุ
- ตรวจสอบเอกสารระบบบริหารจัดการโรงคัดบรรจุ
- ประเมินมาตรฐาน GMP / HACCP
- บันทึกผลการตรวจเอกสาร
- เสนอผลการพิจารณาในระบบ EL

---

# 3. ข้อมูลโรงคัดบรรจุ

ข้อมูลพื้นฐานของโรงคัดบรรจุที่ใช้ในการพิจารณา

- รหัสรับรองโรงคัดบรรจุ
- วันที่ออกใบรับรอง
- วันที่หมดอายุ
- ชื่อโรงคัดบรรจุ
- ชื่อผู้ติดต่อ
- ที่อยู่โรงคัดบรรจุ
- จังหวัด / อำเภอ / ตำบล
- รหัสไปรษณีย์
- โทรศัพท์ / โทรสาร
- อีเมล
- สถานะการรับรอง

---

# 4. ระบบการจัดการโรงคัดบรรจุ

เจ้าหน้าที่ต้องตรวจสอบระบบการจัดการของโรงคัดบรรจุ เช่น

- ชนิดพืชที่ดำเนินการ
- ระบบการควบคุมคุณภาพ
- ระบบการตรวจสอบย้อนกลับ
- ระบบการจัดการความปลอดภัยอาหาร

---

# 5. การตรวจสอบเอกสารมาตรฐาน

เจ้าหน้าที่ตรวจสอบเอกสารมาตรฐาน เช่น

### 1. ใบรับรอง GMP / HACCP

ตรวจสอบข้อมูล เช่น

- หมายเลขใบรับรอง
- วันที่ออกใบรับรอง
- วันหมดอายุใบรับรอง

---

# 6. แผนการผลิต

ตรวจสอบเอกสาร

- แผนการผลิตพืช
- ปริมาณการผลิต
- แผนการจัดส่งสินค้า

---

# 7. ระบบควบคุมกระบวนการผลิต

เอกสารที่ต้องตรวจ เช่น

- Vendor List (AVL) รายชื่อเกษตรกร / ผู้ส่งมอบ
- ขั้นตอนการผลิต
- ระบบควบคุมคุณภาพ
- ระบบการจัดการสารเคมี
- ระบบการจัดการความปลอดภัยอาหาร

---

# 8. ระบบ HACCP

เอกสาร HACCP ที่ต้องตรวจ เช่น

- HACCP Team
- รายละเอียดผลิตภัณฑ์
- Flow Chart กระบวนการผลิต
- HACCP Plan
- CCP Validation
- HACCP Verification

---

# 9. เอกสารอื่น ๆ

เอกสารประกอบเพิ่มเติม เช่น

- เอกสารควบคุมคุณภาพ
- เอกสารการตรวจสอบย้อนกลับ
- เอกสารการเรียกคืนสินค้า (Recall)

---

# 10. การบันทึกผลการตรวจเอกสาร

เจ้าหน้าที่บันทึกผลการตรวจในระบบ

ผลการตรวจ

- ผ่าน
- ไม่ผ่าน
- รอแก้ไข

พร้อมระบุ

- หมายเหตุ
- เอกสารประกอบ
- หลักฐาน

---

# 11. การสรุปผลการพิจารณา

เมื่อการตรวจเอกสารเสร็จสิ้น

ระบบจะบันทึกข้อมูล

- ผลการตรวจเอกสาร
- ผู้ตรวจ
- วันที่ตรวจ
- สถานะคำขอ

---

# 12. ผลลัพธ์ของกระบวนการ

ผลการพิจารณาจะถูกใช้เพื่อ

- อนุมัติการขึ้นทะเบียนโรงคัดบรรจุในบัญชี EL
- กำหนดสถานะโรงคัดบรรจุ
- ใช้เป็นข้อมูลสำหรับการตรวจติดตาม

---

# 13. สรุป Flow การทำงาน

รับข้อมูลโรงคัดบรรจุจากระบบ EL
│
ตรวจสอบข้อมูลพื้นฐานโรงคัดบรรจุ
│
ตรวจสอบเอกสาร GMP / HACCP
│
ตรวจสอบระบบการผลิตและควบคุมคุณภาพ
│
ตรวจสอบเอกสาร HACCP
│
ตรวจสอบเอกสารประกอบอื่น
│
บันทึกผลการตรวจเอกสาร
│
สรุปผลการพิจารณา
│
กำหนดสถานะในระบบ EL
