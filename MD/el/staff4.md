# หน้าตรวจคำขอ (เจ้าหน้าที่ กตม.)

ระบบ: **Establishment List (EL)**

---

## 1. ข้อมูลทั่วไปของการตรวจ

| Field       | Description                   |
| ----------- | ----------------------------- |
| ชื่อ        | เลือกชื่อผู้ตรวจ              |
| วันที่ตรวจ  | ระบุวันที่ทำการตรวจ           |
| แปลงเกษตรกร | เลือกแปลงเกษตรกรที่เกี่ยวข้อง |

### ตารางแปลงเกษตรกร

| ชื่อเกษตรกร | รหัสใบรับรอง | รหัสแปลง | ที่ตั้ง | ตำบล | อำเภอ | จังหวัด |
| ----------- | ------------ | -------- | ------- | ---- | ----- | ------- |
| -           | -            | -        | -       | -    | -     | -       |

> หากไม่มีข้อมูลจะแสดงข้อความ **"ไม่มีข้อมูล"**

# 2. ผลตรวจเชื้อจุลินทรีย์

เจ้าหน้าที่สามารถเพิ่มผลตรวจได้หลายรายการ

| Field          | Description      |
| -------------- | ---------------- |
| เชื้อ          | เลือกชนิดเชื้อ   |
| ผลตรวจ         | ระบุค่าที่ตรวจพบ |
| ผ่าน / ไม่ผ่าน | ผลการพิจารณา     |
| หมายเหตุ       | ข้อมูลเพิ่มเติม  |

### ตารางผลตรวจ

| เลือก | เชื้อ    | ผลตรวจ | ผ่าน/ไม่ผ่าน | หมายเหตุ | เพิ่ม/แก้ไข |
| ----- | -------- | ------ | ------------ | -------- | ----------- |
| ☐     | Dropdown | Text   | Dropdown     | Text     | ➕          |

**Action**

- ❌ ลบ
- ➕ เพิ่ม

# 5. การทำงานของระบบ (Action)

| Action | Description           |
| ------ | --------------------- |
| เพิ่ม  | เพิ่มรายการผลตรวจใหม่ |
| ลบ     | ลบรายการที่เลือก      |
| แก้ไข  | แก้ไขข้อมูลในรายการ   |

---

# 6. พฤติกรรมการใช้งาน (UX Behavior)

### การเพิ่มรายการ

เมื่อกดปุ่ม **➕ เพิ่ม**

ระบบจะ

- เพิ่มแถวใหม่ในตาราง
- เปิดช่องให้กรอกข้อมูลหรือเลือกค่า

### การลบรายการ

เมื่อกดปุ่ม **❌ ลบ**

ระบบจะ

- ลบรายการที่ถูกเลือกออกจากตาราง
