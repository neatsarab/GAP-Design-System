# ระบบการควบคุมพิเศษบัญชีรายชื่อโรงคัดบรรจุ (Establishment List : EL)

## ฝั่งเจ้าหน้าที่ สวพ.

ระบบนี้ใช้สำหรับเจ้าหน้าที่ **สวพ. (สำนักวิจัยและพัฒนาการเกษตร)** ในการตรวจสอบ ประเมิน และติดตามสถานประกอบการโรงคัดบรรจุที่อยู่ในบัญชี Establishment List (EL) เพื่อควบคุมมาตรฐานก่อนการส่งออก

---

# 1. Information Architecture (IA)

เมนูหลักในระบบของเจ้าหน้าที่ สวพ.

- รายการตรวจเวลาร EL
- รายการตรวจ EL (CL-02)
- ตรวจติดตาม EL (CL-02)
- แจ้งเตือน/ทบทวน
- ข้อมูลระบบ
- รายงานผลการดำเนินงาน

---

# 2. ขั้นตอนการทำงานของเจ้าหน้าที่

กระบวนการทำงานแบ่งเป็น 4 ขั้นตอนหลัก

1. ข้อมูลคำขอ
2. นัดตรวจแปลง
3. ผลตรวจแปลง
4. รายงานผล

---

# 3. ขั้นตอนที่ 1 : ตรวจสอบข้อมูลคำขอ

เจ้าหน้าที่ สวพ. ตรวจสอบข้อมูลสถานประกอบการและข้อมูลแปลงเกษตรกร

### ข้อมูลที่ตรวจสอบ

- ชื่อเกษตรกร
- ชนิดพืช
- ประเภทการรับรอง (เช่น GAP)
- รหัสใบรับรอง
- พื้นที่เพาะปลูก
- พิกัดแปลง (X,Y,Z)
- ที่ตั้งแปลงเกษตร

---

# 4. การตรวจสอบเอกสารประกอบ

เจ้าหน้าที่ตรวจสอบเอกสารที่แนบมาในระบบ เช่น

- ตารางรายชื่อเกษตรกร
- สำเนาใบรับรอง GAP (ถ้ามี)
- สัญญาซื้อขายระหว่างโรงคัดบรรจุและเกษตรกร
- หนังสือยินยอมการใช้สารเคมี

---

# 5. เอกสารแผนการควบคุม

เจ้าหน้าที่ตรวจสอบแผนงานของโรงคัดบรรจุ เช่น

- แผนการบริหารจัดการระบบควบคุม
- แผนการตรวจติดตามแปลง
- แผนการจัดการสารเคมี
- แผนการเก็บเกี่ยวและการจัดการหลังการเก็บเกี่ยว
- แผนการตรวจสอบย้อนกลับ
- แผนการจัดการความเสี่ยง

---

# 6. การบันทึกผลการตรวจ

เจ้าหน้าที่บันทึกผลการพิจารณาในระบบ

### ผลการตรวจ

- ผ่าน
- ปรับปรุง
- ไม่ผ่าน

พร้อมระบุ

- หมายเหตุ
- เหตุผลในการพิจารณา

---

# 7. การมอบหมายพื้นที่ตรวจ

เจ้าหน้าที่สามารถกำหนดพื้นที่รับผิดชอบ เช่น

- สวพ. เขต
- สวพ. จังหวัด

เพื่อให้หน่วยงานในพื้นที่ดำเนินการตรวจสอบ

---

# 8. การบันทึกผลการตรวจแปลง

เมื่อมีการตรวจแปลงจริง เจ้าหน้าที่จะ

1. บันทึกผลการตรวจ
2. ระบุข้อบกพร่อง (ถ้ามี)
3. บันทึกข้อเสนอแนะในการปรับปรุง

---

# 9. การสรุปรายงานผล

หลังจากตรวจสอบครบถ้วน ระบบจะ

- สรุปผลการตรวจ
- บันทึกสถานะการรับรอง
- จัดทำรายงานผลการดำเนินงาน

---

# 10. ผลลัพธ์ของกระบวนการ

เมื่อการพิจารณาเสร็จสิ้น

- โรงคัดบรรจุจะได้รับสถานะในบัญชี EL
- ข้อมูลจะถูกนำไปใช้ในการควบคุมมาตรฐานการส่งออก
- สามารถตรวจสอบย้อนหลังได้ในระบบ

---

# 11. สรุป Flow การทำงาน

รับคำขอจากผู้ประกอบการ
│
ตรวจสอบข้อมูลคำขอ
│
ตรวจสอบเอกสารประกอบ
│
นัดหมายตรวจแปลง
│
ดำเนินการตรวจแปลง
│
บันทึกผลการตรวจ
│
ประเมินผล (ผ่าน / ปรับปรุง / ไม่ผ่าน)
│
จัดทำรายงานผล
│
บันทึกสถานะในระบบ EL
