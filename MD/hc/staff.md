# ระบบออกใบรับรองสุขอนามัย (Health Certificate) ตามประกาศพืชควบคุมเฉพาะ

## ฝั่งเจ้าหน้าที่

ระบบนี้ใช้สำหรับ **เจ้าหน้าที่กรมวิชาการเกษตร** เพื่อดำเนินการตรวจสอบคำขอ วิเคราะห์ผลตัวอย่าง พิจารณาอนุมัติ และออกใบรับรองสุขอนามัยตามประกาศพืชควบคุมเฉพาะ

---

# 1. โครงสร้างหน้าจอระบบ

หน้าจอระบบแบ่งออกเป็น 3 ส่วนหลัก

HC staff System
│
├─ Sidebar Navigation
├─ Request List (รายการคำขอ)
└─ Workflow Processing

---

# 2. Sidebar Menu (เมนูด้านซ้าย)

เมนูใช้สำหรับเข้าถึงขั้นตอนการทำงานของเจ้าหน้าที่

## รายการคำขอ

เมนูหลักสำหรับจัดการคำขอใบรับรอง

### เมนูย่อย

- **รายการคำขอทั้งหมด**  
  แสดงรายการคำขอทั้งหมดในระบบ

- **ตรวจสอบคำขอ**  
  ตรวจสอบข้อมูลคำขอและเอกสารประกอบ

- **ผลตรวจตัวอย่าง**  
  บันทึกผลตรวจจากห้องปฏิบัติการ

- **พิจารณาผลตรวจตัวอย่าง**  
  วิเคราะห์และตัดสินผลการตรวจ

- **พิจารณาออกใบรับรอง**  
  ตัดสินใจอนุมัติการออกใบรับรอง

- **พิจารณาแบบร่าง**  
  ตรวจสอบ Draft ของใบรับรองก่อนออกจริง

---

## ลงนาม

สำหรับผู้มีอำนาจในการลงนาม

- ลงนามใบรับรอง
- ยืนยันเอกสาร

---

## ข้อมูลทะเบียน

จัดการข้อมูลทะเบียนที่เกี่ยวข้อง เช่น

- ผู้ส่งออก
- โรงคัดบรรจุ
- แหล่งผลิต

---

## ข้อมูลภาพรวม

Dashboard สำหรับดูสถิติ เช่น

- จำนวนคำขอ
- สถานะคำขอ
- จำนวนใบรับรองที่ออกแล้ว

---

# 3. หน้ารายการคำขอ

หน้าจอนี้ใช้สำหรับค้นหาและจัดการคำขอ

## ตัวกรองข้อมูล

เจ้าหน้าที่สามารถค้นหาคำขอโดย

- วันที่ยื่นคำขอ
- ประเภทคำขอ
- สถานะคำขอ

### ปุ่มการทำงาน

- **ค้นหา**
- **ล้าง**

---

## ตารางรายการคำขอ

ตารางจะแสดงข้อมูลคำขอ เช่น

| Field          | รายละเอียด      |
| -------------- | --------------- |
| เลขคำขอ        | หมายเลขคำขอ     |
| ประเภทคำขอ     | ประเภทเอกสาร    |
| ผู้ส่งออก      | ชื่อผู้ยื่นคำขอ |
| วันที่ยื่นคำขอ | วันที่ส่งคำขอ   |
| สถานะคำขอ      | สถานะกระบวนการ  |
| Action         | ปุ่มจัดการคำขอ  |

---

# 4. Workflow การดำเนินการของเจ้าหน้าที่

ระบบมีขั้นตอนหลักดังนี้

1 ข้อมูลคำขอ
2 ตรวจตัวอย่าง / พิจารณาผลตรวจ
3 พิจารณาออกใบรับรอง
4 ลงนาม

---

# 5. Step 1 : ข้อมูลคำขอ

เจ้าหน้าที่ตรวจสอบข้อมูลคำขอ เช่น

- ข้อมูลผู้ส่งออก
- ข้อมูลสินค้า
- ประเทศปลายทาง
- เอกสารประกอบ

หากข้อมูลไม่ถูกต้อง

- ส่งกลับให้ผู้ประกอบการ **แก้ไขคำขอ**

---

# 6. Step 2 : ตรวจตัวอย่าง / พิจารณาผลตรวจ

ในขั้นตอนนี้เจ้าหน้าที่จะ

1. ตรวจสอบผลตรวจจากห้องปฏิบัติการ
2. วิเคราะห์ผล

ผลลัพธ์ที่เป็นไปได้

| ผลการพิจารณา | ความหมาย                   |
| ------------ | -------------------------- |
| ผ่าน         | สามารถดำเนินการออกใบรับรอง |
| ปรับปรุง     | ต้องแก้ไขข้อมูล            |
| ไม่ผ่าน      | ไม่สามารถออกใบรับรองได้    |

เจ้าหน้าที่สามารถระบุ

- **หมายเหตุ / เหตุผล**

---

# 7. Step 3 : พิจารณาออกใบรับรอง

หลังจากผลตรวจผ่าน

เจ้าหน้าที่จะ

- ตรวจสอบความถูกต้องของข้อมูล
- ตรวจสอบ Draft ของใบรับรอง

จากนั้น

- อนุมัติการออกใบรับรอง

---

# 8. Step 4 : ลงนาม

ขั้นตอนสุดท้ายของกระบวนการ

ผู้มีอำนาจจะ

- ลงนามในใบรับรองสุขอนามัย

เมื่อเสร็จแล้วระบบจะ

- Generate ใบรับรอง
- เปลี่ยนสถานะคำขอเป็น **Completed**

---

# 9. สถานะคำขอในระบบ

ตัวอย่างสถานะคำขอ

| Status           | ความหมาย                |
| ---------------- | ----------------------- |
| Draft            | กำลังกรอกคำขอ           |
| Submitted        | ยื่นคำขอแล้ว            |
| Under Review     | อยู่ระหว่างตรวจสอบ      |
| Testing          | อยู่ระหว่างตรวจตัวอย่าง |
| Pending Approval | รอพิจารณา               |
| Approved         | อนุมัติแล้ว             |
| Rejected         | ไม่ผ่านการอนุมัติ       |
| Completed        | ออกใบรับรองแล้ว         |

---

# 10. Action ที่เจ้าหน้าที่สามารถทำได้

เจ้าหน้าที่สามารถดำเนินการ

- ดูรายละเอียดคำขอ
- ตรวจสอบเอกสาร
- บันทึกผลตรวจ
- พิจารณาผลตรวจ
- อนุมัติใบรับรอง
- ส่งเอกสารให้ลงนาม

---
