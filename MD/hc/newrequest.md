# ระบบการออกใบรับรองสุขอนามัย (Health Certificate) ตามประกาศพืชควบคุมเฉพาะ

> เอกสารนี้อธิบายรายละเอียดหน้าจอ ฟิลด์ เงื่อนไข และการทำงานของระบบยื่นคำขอใบรับรองสุขอนามัย สำหรับพืชควบคุมเฉพาะ โดยแบ่งเป็น 3 ขั้นตอนหลัก ได้แก่ ข้อมูลผู้ส่งออก, ข้อมูลรายละเอียด และไฟล์แนบ

## 1. ภาพรวมการทำงาน

ระบบประกอบด้วยขั้นตอนการยื่นคำขอ 3 ขั้นตอน ได้แก่

1. ข้อมูลผู้ส่งออก
2. ข้อมูลรายละเอียด
3. ไฟล์แนบ

โดยผู้ใช้งานสามารถกดปุ่ม `ย้อนกลับ` และ `ถัดไป` เพื่อเปลี่ยนขั้นตอน รวมถึงสามารถกด `แบบร่าง` เพื่อบันทึกคำขอชั่วคราวได้ทุกขั้นตอน

---

# Step 1: ข้อมูลผู้ส่งออก

## ข้อมูลที่ต้องกรอก

### 1. เลือกหน่วยงาน

- Dropdown เลือกหน่วยงาน
- ดึงข้อมูลจาก Master Data
- เป็น Required Field

### 2. ประเภททะเบียนที่ใช้ในการส่งออก

เลือกได้ 1 ตัวเลือก

- มี DOA และ GAP
- ไม่มี DOA และ/หรือ GAP

> ใช้กำหนดว่าตารางข้อมูลส่งออกและฟิลด์ที่เกี่ยวข้องกับ GAP / DOA จะแสดงหรือไม่

### 3. ระยะเวลาสำหรับส่งออก

- Dropdown เลือกจำนวนวัน
- ตัวเลือก:
  - 7 วัน
  - 14 วัน
  - 30 วัน

### 4. วันที่เริ่มต้น

- Date Picker
- Required

### 5. วันที่สิ้นสุด

- Date Picker
- Required
- ระบบคำนวณหรือ Validate ต้องไม่ก่อนวันที่เริ่มต้น

---

## ตารางข้อมูลผู้ส่งออก

สามารถกด `เพิ่มข้อมูล` เพื่อเพิ่มรายการผู้ส่งออกได้หลายรายการ

### Columns

| ชื่อข้อมูล          | รายละเอียด                 |
| ------------------- | -------------------------- |
| เลขทะเบียนผู้ส่งออก | Text / Readonly จากทะเบียน |
| เลขทะเบียน DOA      | Text                       |
| รหัสรับรอง GAP      | Text                       |
| ประเภทของพืช        | Dropdown / Text            |
| วันที่ขึ้นทะเบียน   | Date                       |
| วันหมดอายุทะเบียน   | Date                       |
| จัดการข้อมูล        | Edit / Delete              |

### การทำงาน

- กด `เพิ่มข้อมูล` เพื่อเปิด Modal เพิ่มข้อมูลผู้ส่งออก
- สามารถแก้ไขข้อมูลด้วยปุ่ม `Edit`
- สามารถลบข้อมูลด้วยปุ่ม `Delete`
- ต้องมีอย่างน้อย 1 รายการก่อนกดถัดไป

---

## การส่งตรวจ Lab

### ตัวเลือก

เลือกได้ 1 ตัวเลือก

- ไม่ส่ง Lab
- ส่ง Lab

หากเลือก `ส่ง Lab` ให้แสดงฟิลด์เพิ่มเติมดังนี้

### ห้องปฏิบัติการ

- Dropdown เลือกห้องปฏิบัติการ
- ดึงข้อมูลจาก Master Data
- เลือกได้เพียง 1 ห้องปฏิบัติการ
- Required เมื่อเลือกส่ง Lab

### เลือกสินค้า

- Dropdown เลือกสินค้า
- ดึงข้อมูลจาก Master Data
- Required

# Step 2: ข้อมูลรายละเอียด

## 1. ข้อมูลผู้ประกอบการโรงคัดบรรจุ

ข้อมูลส่วนนี้แสดงแบบ Read Only และดึงจากข้อมูล DOA ที่เลือกใน Step 1

### แสดงข้อมูล

| ชื่อข้อมูล                            | ที่มา |
| ------------------------------------- | ----- |
| ชื่อและที่อยู่ผู้ประกอบการโรงคัดบรรจุ | DOA   |
| จังหวัด                               | DOA   |
| รหัสไปรษณีย์                          | DOA   |
| โทรศัพท์                              | DOA   |
| โทรสาร                                | DOA   |

---

## 2. รหัสโรงคัดบรรจุ / ชื่อสถานที่โรงคัดบรรจุ

ข้อมูลส่วนนี้เป็น Read Only จาก DOA เช่นกัน

| ชื่อข้อมูล                | ที่มา |
| ------------------------- | ----- |
| รหัสโรงคัดบรรจุ           | DOA   |
| ชื่อและที่อยู่โรงคัดบรรจุ | DOA   |
| จังหวัด                   | DOA   |
| รหัสไปรษณีย์              | DOA   |
| โทรศัพท์                  | DOA   |
| โทรสาร                    | DOA   |

---

## 3. ข้อมูลผู้ส่งออก

### ชื่อและที่อยู่ผู้ส่งออก

- Textarea
- สามารถกรอกเอง หรือแนบรายละเอียดเพิ่มเติม

### จังหวัด

- Text

### รหัสไปรษณีย์

- Text

### โทรศัพท์

- Text

### โทรสาร

- Text

### ชื่อและที่อยู่ผู้รับสินค้า

- Textarea

### แนบรายละเอียดเพิ่มเติม

- Checkbox: `ตามรายละเอียดที่แนบ`
- เมื่อเลือก ให้ระบบถือว่ารายละเอียดผู้ส่งออก / ผู้รับสินค้าอยู่ในเอกสารแนบ

---

## 4. ยานพาหนะ / วันที่ส่งออก

### ยานพาหนะ

- Text Input
- ตัวอย่าง: เรือ, เครื่องบิน, รถบรรทุก, เที่ยวบิน

### วันที่ส่งออก

- Date Picker
- ดึงค่าจากวันที่ที่เลือกใน Step 1 หรือสามารถแก้ไขได้

---

## 5. รายการสิ่งที่ต้องการให้ระบุในใบรับรอง

### ชื่อเชื้อจุลินทรีย์หรือสิ่งอื่นใดที่เป็นอันตรายต่อมนุษย์

- Multi Select จาก Master Data
- เลือกได้มากกว่า 1 รายการ
- เมื่อเลือกหลายรายการ ให้แสดงคั่นด้วยเครื่องหมายจุลภาค

ตัวอย่าง:

- Salmonella
- E.coli
- Heavy Metal
- Pesticide Residue

---

## 6. รายละเอียดการส่งออกสินค้า (พก.11.1)

สามารถเพิ่มได้หลายรายการ โดยกด `+เพิ่มข้อมูล`

### Columns

| ชื่อข้อมูล          | รายละเอียด             |
| ------------------- | ---------------------- |
| ลำดับ               | Running Number         |
| ประเภทใบรับรอง      | Dropdown               |
| เลขทะเบียนผู้ส่งออก | Read Only จาก Step 1   |
| ชื่อผู้ส่งออก       | Read Only              |
| ประเทศปลายทาง       | Dropdown / Master Data |
| ช่วงวันที่ส่งออก    | Date Range             |
| น้ำหนัก             | Number                 |
| จัดการข้อมูล        | Edit / Delete          |

### การทำงาน

- เพิ่ม / แก้ไข / ลบ ได้
- อย่างน้อย 1 รายการก่อนกดถัดไป

---

## 7. ตารางสรุปตัวอย่างสินค้า

| ชื่อข้อมูล             | รายละเอียด                          |
| ---------------------- | ----------------------------------- |
| ตัวอย่างที่            | Running Number                      |
| ชื่อพืช                | ดึงจากข้อมูลสินค้าใน Step 1         |
| น้ำหนัก (กก.)          | รวมจากรายละเอียดการส่งออกทั้งหมด    |
| มูลค่า (บาท)           | Text Input                          |
| รหัสแปลง GAP / Organic | ดึงจาก Step 1 หากมีมากกว่า 1 รายการ |

### เงื่อนไข

- น้ำหนักรวม = SUM ของน้ำหนักในรายละเอียดการส่งออกทั้งหมด
- หากมีหลายแปลง GAP ให้แสดงทั้งหมดในรูปแบบ Comma Separated หรือ Tag

---

# Step 3: ไฟล์แนบ

ผู้ใช้งานสามารถเลือกเอกสารที่แนบมาพร้อมคำขอได้มากกว่า 1 รายการ

## รายการเอกสาร

### 1. สำเนาบัตรประจำตัวประชาชนหรือหนังสือเดินทาง

- Checkbox
- Upload File รองรับ PDF / JPG / PNG

### 2. สำเนาหนังสือรับรองการจดทะเบียนนิติบุคคล

- Checkbox
- Upload File
- ต้องออกไม่เกิน 6 เดือน

### 3. สำเนาบัตรประชาชนของผู้มีอำนาจลงนาม

- Checkbox
- Upload File

### 4. หนังสือมอบอำนาจ

- Checkbox
- Upload File

### 5. เอกสารอื่น ๆ

- Checkbox
- Text Input ระบุรายละเอียด
- Upload File

---

## Validation

- หากเลือก Checkbox ของเอกสารใด ต้องแนบไฟล์อย่างน้อย 1 ไฟล์
- รองรับไฟล์:
  - PDF
  - JPG
  - PNG

- ขนาดไฟล์ไม่เกิน 10 MB ต่อไฟล์

---

# ปุ่มการทำงาน

| ปุ่ม       | การทำงาน              |
| ---------- | --------------------- |
| ย้อนกลับ   | กลับไปขั้นตอนก่อนหน้า |
| ถัดไป      | ไปขั้นตอนถัดไป        |
| แบบร่าง    | บันทึกข้อมูลชั่วคราว  |
| ยืนยันคำขอ | ส่งคำขอเข้าสู่ระบบ    |

---

# เงื่อนไขก่อนส่งคำขอ

ระบบจะสามารถกด `ยืนยันคำขอ` ได้เมื่อ

- กรอกข้อมูลครบทุก Required Field
- มีข้อมูลผู้ส่งออกอย่างน้อย 1 รายการ
- มีรายละเอียดการส่งออกอย่างน้อย 1 รายการ
- หากเลือกส่ง Lab ต้องเลือกห้องปฏิบัติการและสินค้า
- หากเลือกแนบเอกสาร ต้องมีไฟล์แนบครบ

---

# สถานะคำขอหลังส่ง

- แบบร่าง
- รอตรวจสอบ
- รอแก้ไขข้อมูล
- อนุมัติ
- ไม่อนุมัติ
- ออกใบรับรองแล้ว
