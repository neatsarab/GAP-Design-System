# ระบบยื่นคำขอใบรับรองสุขอนามัย (Health Certificate) ตามประกาศพืชควบคุมเฉพาะ

เอกสารนี้อธิบาย **กระบวนการยื่นคำขอใบรับรองสุขอนามัย (Health Certificate)** สำหรับพืชควบคุมเฉพาะ โดยระบบรองรับการยื่นคำขอ 2 ประเภท ได้แก่

1. **แบบคำขอใบรับรองสุขอนามัย ตามประกาศพืชควบคุมเฉพาะ**
2. **แบบคำขอแก้ไขใบรับรองสุขอนามัย**

---

# 1. ประเภทคำขอในระบบ

ระบบรองรับการยื่นคำขอ 2 ประเภทหลัก

## 1.1 แบบคำขอใบรับรองสุขอนามัย (Application for Health Certificate)

ใช้สำหรับ

- การยื่นคำขอ **ออกใบรับรองสุขอนามัยเพื่อการส่งออก**
- สำหรับ **พืชที่อยู่ภายใต้ประกาศพืชควบคุมเฉพาะ**

เอกสารประกอบ

- แบบคำขอใบรับรองสุขอนามัย (Form HC)
- ใบแนบรายการสินค้า (Attachment Sheet)

---

## 1.2 แบบคำขอแก้ไขใบรับรองสุขอนามัย (Correction of Health Certificate)

ใช้ในกรณี

- ต้องการ **แก้ไขข้อมูลในใบรับรอง**
- แก้ไขข้อมูลใน **ใบแนบ (Attachment Sheet)**

เช่น

- ชื่อผู้ส่งออก
- รายละเอียดสินค้า
- ปริมาณสินค้า
- ประเทศปลายทาง

---

# 2. โครงสร้างแบบฟอร์มคำขอ

## 2.1 แบบคำขอใบรับรองสุขอนามัย

ข้อมูลสำคัญที่ต้องกรอก

### ข้อมูลผู้ยื่นคำขอ

- ชื่อผู้ส่งออก (Exporter)
- ที่อยู่
- จังหวัด
- รหัสไปรษณีย์
- โทรศัพท์
- โทรสาร

---

### ข้อมูลโรงคัดบรรจุ (Packing House)

- รหัสโรงคัดบรรจุ
- ชื่อและที่อยู่โรงคัดบรรจุ
- จังหวัด
- โทรศัพท์

---

### ข้อมูลผู้รับสินค้า (Consignee)

- ชื่อผู้รับสินค้า
- ที่อยู่
- ประเทศปลายทาง

---

### รายละเอียดสินค้า

| Field              | รายละเอียด    |
| ------------------ | ------------- |
| Sample No          | เลขตัวอย่าง   |
| Name of plants     | ชื่อพืช       |
| Weight             | น้ำหนัก       |
| Value              | มูลค่า        |
| GAP / Organic Code | รหัสแหล่งผลิต |

---

### เอกสารแนบ

ตัวอย่างเอกสารที่ต้องแนบ

- ใบกำกับสินค้า
- ใบขนสินค้า
- ใบรับรองแหล่งผลิต
- เอกสารส่งออกอื่น ๆ

---

## 2.2 แบบใบแนบคำขอ (Attachment Sheet)

ใช้ระบุรายละเอียดสินค้าเพิ่มเติม

| Field                   | รายละเอียด       |
| ----------------------- | ---------------- |
| Manufacturer or Shipper | ผู้ผลิต / ผู้ส่ง |
| Address                 | ที่อยู่          |
| Consignee               | ผู้รับสินค้า     |
| Registration No         | เลขทะเบียน       |
| Weight                  | น้ำหนักสินค้า    |

---

## 2.3 แบบคำขอแก้ไขใบรับรอง

ใช้สำหรับแก้ไขข้อมูลในใบรับรอง

ข้อมูลที่ต้องระบุ

- เลขที่ใบรับรอง
- วันที่ออกใบรับรอง
- วันที่หมดอายุ
- รายการที่ต้องการแก้ไข

ตารางการแก้ไข

| ลำดับ | หน้า | รายการเดิม | รายการใหม่ |
| ----- | ---- | ---------- | ---------- |

---

# 3. Workflow กระบวนการยื่นคำขอ HC

กระบวนการทำงานแบ่งตามบทบาทของผู้เกี่ยวข้อง

ผู้ประกอบการ
เจ้าหน้าที่
ห้องปฏิบัติการเอกชน
ผู้พิจารณาผล
ผู้ลงนาม

---

# 4. Flow การดำเนินงาน

## 4.1 ผู้ประกอบการ

1. เริ่มต้นกระบวนการ
2. ยื่นคำขอ (กรอก Detail)
3. แนบเอกสารประกอบ

กรณีข้อมูลไม่ครบ

- ระบบให้ **แก้ไขคำขอ**

---

## 4.2 เจ้าหน้าที่

1. ตรวจสอบความถูกต้องของข้อมูล

### กรณีไม่ต้องตรวจตัวอย่าง

- ดำเนินการพิจารณาต่อ

### กรณีต้องตรวจตัวอย่าง

- ส่งตัวอย่างไปตรวจในห้องปฏิบัติการ

---

## 4.3 ห้องปฏิบัติการเอกชน

ดำเนินการ

- ตรวจตัวอย่างสินค้า
- วิเคราะห์ผล

จากนั้น

- จัดทำรายงานผลตรวจ
- ส่งผลกลับเข้าสู่ระบบ

---

## 4.4 ผู้พิจารณาผล

พิจารณา

- คำขอ
- เอกสารประกอบ
- ผลตรวจตัวอย่าง

### กรณีแก้ไข

- ส่งกลับให้เจ้าหน้าที่แก้ไขข้อมูล

---

## 4.5 เจ้าหน้าที่ดำเนินการออกใบรับรอง

เมื่อคำขอผ่านการพิจารณา

เจ้าหน้าที่จะ

1. ตรวจสอบข้อมูลอีกครั้ง
2. ยืนยันแบบร่างใบรับรอง

---

## 4.6 การออกใบรับรอง

ระบบดำเนินการ

- สร้างเลขใบรับรอง
- Generate เอกสาร

---

## 4.7 การลงนาม

ผู้มีอำนาจ

- ลงนามในใบรับรอง

---

## 4.8 ผู้ประกอบการ

ดำเนินการ

- ชำระค่าธรรมเนียม
- รับใบรับรอง

ช่องทาง

- รับผ่านระบบ
- หรือรับที่สำนักงาน

---

# 5. สถานะคำขอในระบบ

ตัวอย่างสถานะคำขอ

| Status              | ความหมาย                |
| ------------------- | ----------------------- |
| Draft               | กำลังกรอกคำขอ           |
| Submitted           | ยื่นคำขอแล้ว            |
| Under Review        | อยู่ระหว่างตรวจสอบ      |
| Sample Testing      | อยู่ระหว่างตรวจตัวอย่าง |
| Pending Approval    | รอการอนุมัติ            |
| Approved            | อนุมัติแล้ว             |
| Correction Required | ต้องแก้ไข               |
| Completed           | เสร็จสิ้น               |
