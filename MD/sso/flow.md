# กระบวนการลงทะเบียนและเข้าสู่ระบบด้วย Single Sign-On (SSO)

เอกสารนี้อธิบายขั้นตอนการลงทะเบียนและเข้าสู่ระบบของผู้ใช้งานผ่านระบบ **Single Sign-On (SSO)** โดยมีการเชื่อมต่อกับฐานข้อมูลภายนอก เช่น **ThaiD API** และ **DBD (กรมพัฒนาธุรกิจการค้า)** เพื่อใช้ตรวจสอบข้อมูลผู้ใช้งาน

---

# ภาพรวมระบบ

กระบวนการประกอบด้วย 3 ส่วนหลัก

1. ผู้ประกอบการ / ผู้ใช้งานระบบ
2. ระบบ SSO
3. เจ้าหน้าที่

---

# ขั้นตอนการทำงานของระบบ

## 1. เริ่มต้นเข้าสู่ระบบ

ผู้ใช้งานเริ่มต้นเข้าใช้งานระบบผ่านหน้า **SSO Login**

### ขั้นตอน

1. ผู้ใช้งานเข้าสู่ **ระบบ SSO**
2. ระบบตรวจสอบสถานะผู้ใช้งาน

---

# 2. ตรวจสอบประเภทผู้ใช้งาน

ระบบจะแยกผู้ใช้งานออกเป็น 2 กรณี

- ผู้ใช้ใหม่
- ผู้ใช้เดิมที่มีบัญชีอยู่แล้ว

---

# 3. กรณีผู้ใช้เดิม

ผู้ใช้ที่เคยมีบัญชีอยู่แล้วสามารถเข้าสู่ระบบได้ทันที

### ขั้นตอน

1. กรอก
   - Username
   - Password  
     หรือ
   - ใช้บัญชี **ThaiD**

2. ระบบตรวจสอบข้อมูลผู้ใช้งาน

### ผลลัพธ์

- หาก **พบข้อมูลผู้ใช้**  
  → เข้าสู่ระบบตามสิทธิ์ที่ได้รับ

- หาก **ไม่พบข้อมูลผู้ใช้**  
  → ระบบจะนำกลับไปยังหน้า **SSO Login**

---

# 4. กรณีผู้ใช้ใหม่

ผู้ใช้งานต้องดำเนินการ **ลงทะเบียนใหม่**

### ขั้นตอน

1. เลือก **ลงทะเบียนผู้ใช้งานใหม่**
2. ยืนยันตัวตนผ่าน **ThaiD**
3. เลือกประเภทการลงทะเบียน

ตัวอย่างประเภท

- บุคคลธรรมดา
- นิติบุคคล
- ตัวแทน
- อื่น ๆ

---

# 5. การตรวจสอบข้อมูลจากหน่วยงานภายนอก

หลังจากเลือกประเภทผู้ใช้งาน ระบบจะดึงข้อมูลจากระบบภายนอก

## กรณีนิติบุคคล

ระบบตรวจสอบข้อมูลจาก

**DBD (กรมพัฒนาธุรกิจการค้า)**

### ข้อมูลที่ตรวจสอบ

- เลขทะเบียนบริษัท
- ชื่อบริษัท
- สถานะบริษัท

---

## กรณีบุคคลธรรมดา

ระบบเชื่อมต่อกับ

**ThaiD API**

เพื่อดึงข้อมูลผู้ใช้งาน

### ข้อมูลที่ดึงมา

- เลขบัตรประชาชน
- ชื่อ - นามสกุล
- ข้อมูลประจำตัวผู้ใช้งาน

---

# 6. Auto Fill ข้อมูลผู้ใช้งาน

เมื่อระบบดึงข้อมูลจาก API แล้ว ระบบจะ **เติมข้อมูลอัตโนมัติ**

### ข้อมูลที่ Auto Fill

- เลขทะเบียนบริษัท
- ชื่อนิติบุคคล (TH / ENG)
- ประเภทนิติบุคคล
- เลขบัตรประชาชน
- ชื่อ - นามสกุล

ผู้ใช้งานสามารถตรวจสอบและแก้ไขข้อมูลเพิ่มเติมได้

---

# 7. กรอกข้อมูลเพิ่มเติม

ผู้ใช้งานต้องกรอกข้อมูลเพิ่มเติม เช่น

- ที่อยู่
- ข้อมูลติดต่อ
- เอกสารประกอบ

จากนั้นกดยืนยันการลงทะเบียน

---

# 8. ระบบตรวจสอบข้อมูล

ระบบจะตรวจสอบ

- ความถูกต้องของข้อมูล
- เอกสารที่แนบ

---

# 9. กรณีข้อมูลไม่ครบหรือไม่ผ่าน

ผู้ใช้งานจะได้รับการแจ้งเตือน

### สถานะ

- ข้อมูลไม่ครบ
- เอกสารไม่ถูกต้อง

ผู้ใช้งานต้องแก้ไขข้อมูลและส่งใหม่

---

# 10. กรณีข้อมูลถูกต้อง

ระบบจะส่งข้อมูลให้ **เจ้าหน้าที่ตรวจสอบ**

### เจ้าหน้าที่ดำเนินการ

1. ตรวจสอบข้อมูลและเอกสาร
2. พิจารณาการอนุมัติสิทธิ์

---

# 11. การอนุมัติสิทธิ์

หากข้อมูลถูกต้อง

เจ้าหน้าที่จะ **อนุมัติสิทธิ์การใช้งาน**

ผู้ใช้งานสามารถเข้าใช้งานระบบได้

---

# 12. การแจ้งผลการลงทะเบียน

ระบบจะส่ง

- **Email**
- **OTP**

เพื่อยืนยันการลงทะเบียน

### ขั้นตอน

1. ผู้ใช้งานกดยืนยันผ่านลิงก์
2. ระบบเปิดสิทธิ์การเข้าใช้งาน

---

# ผลลัพธ์ของกระบวนการ

ผู้ใช้งานสามารถ

- เข้าสู่ระบบผ่าน **SSO**
- ใช้งานระบบตาม **Role และสิทธิ์ที่ได้รับ**

---

# สรุปการเชื่อมต่อระบบ

| ระบบ      | หน้าที่                  |
| --------- | ------------------------ |
| SSO       | ระบบยืนยันตัวตนผู้ใช้งาน |
| ThaiD API | ตรวจสอบตัวตนบุคคล        |
| DBD       | ตรวจสอบข้อมูลนิติบุคคล   |
| ระบบหลัก  | จัดการบัญชีผู้ใช้งาน     |

---

# บทสรุป

ระบบ SSO ช่วยให้ผู้ใช้งานสามารถ

- ลงทะเบียนได้สะดวก
- ใช้ข้อมูลจากหน่วยงานรัฐโดยตรง
- ลดการกรอกข้อมูลซ้ำ
- เพิ่มความถูกต้องของข้อมูลผู้ใช้งาน
